# animator studio 2.1.5

The Animator Studio on **ReSkate 20261116**: everything ReSkate's two newest updates bring, with the studio in it. Your tricks, packs and playlists stay as they are.

## how to get it

- **Still on Animator Studio 2.1.4?** SETTINGS > UPDATES > UPDATE NOW installs it.
- **Let the ReSkate launcher update to 20261116?** That put base ReSkate's DLL back, so the studio is gone. Download `ReSkate.dll` from this release. Put it in your ReSkate folder in place of the one there, as when you first installed the studio. Turn the launcher's ReSkate updates off, or it swaps the DLL back on the next start.

## fixed

- **With the studio open, the keyboard no longer answers the card that asks about a new plugin.** Close the studio and Enter answers it.

## what comes with ReSkate 20261115 and 20261116

- **One card for all new plugins.** The game asks about them one after another, and you can go back and change an answer.
- **Sounds from mods and players' voices play at 48 kHz**, and mod sounds no longer crackle after a long frame.
- **DualSense:** the skater no longer returns to the session marker while a menu is open.
- **Hosting:** the player count starts within the 32-player limit. On a new profile, the game refused Host.

ReSkate's own launcher also has a new home screen, a roomier Mod Manager and changelogs for every recent release. UPDATE NOW only replaces `ReSkate.dll`, so the launcher you have stays as it is. You get the new one by letting the ReSkate launcher update once and then putting the studio's `ReSkate.dll` back (the second way above).

The rest is in the ReSkate [20261115](https://github.com/Dingo-Shenanigans/ReSkate/releases/tag/20261115) and [20261116](https://github.com/Dingo-Shenanigans/ReSkate/releases/tag/20261116) releases.
