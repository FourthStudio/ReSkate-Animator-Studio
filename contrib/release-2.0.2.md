# animator studio 2.0.2

A fix on 2.0.1, built for **ReSkate 2.1.4-2**. SETTINGS > UPDATES > UPDATE NOW installs it. Your tricks, packs and playlists stay as they are.

## fixed

- **The feet jumped for a moment after every trick.** As a trick handed back to the game, the studio lifted any shoe it found in the deck up onto it, and dropped it back once the blend was over. The game itself stands a shoe a little into the deck, so this happened after every trick, even ones that only change the hands. A shoe now stays as deep as the game has it, and no deeper: keyed legs still never push a foot through the board.
