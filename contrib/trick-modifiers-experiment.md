# Trick modifiers experiment

The current experiment integrates the modifier into the Library workspace and trainer, including
native grinds, manuals, grabs and recognised moving animation pieces. It is built for ReSkate 2.1.3.

See [Library workspace and trick modifiers](library-workspace.md) for setup, selection rules, local
playlist exclusions, testing and the limits of the existing native recognisers.

Use **F8 > LIBRARY > ONE INPUT. TWO STYLES. > SET UP**. Choose a separate modifier playlist and a
controller button. **Replace native button** reserves that button during gameplay; the setting is
shared with the trainer's **ANIMATOR STUDIO > TRICK MODIFIER** card. The bind starts OFF and stays local.

Keep a copy of the previous DLL and ReSkate.Tricks before testing in a separate installation.
Only automated selection/input/UI checks have been performed on this build; complete its live
acceptance checks before sharing it as a stable release. No game assets are included.
